# مهارة: من أي مادة إلى فيديو قصير عمودي (9:16)

تحوّل **أي مادة** (موقع، شرائح، PDF، محاضرة، تطبيق، كود، بيانات، صور، أو مفهوم نظري) إلى فيديو قصير احترافي بخط إنتاج **محلي** مُدار بملفات إعداد، وبنظام تصميم قابل للتخصيص.

## 0) ما تقدّمه المهارة
| المكوّن | الملف | الوظيفة |
|---|---|---|
| خط الإنتاج | `scripts/` | تهيئة مشروع، تسجيل مواد ويب بمؤشر ماوس، توليد المشاهد، رندر، مزج صوت، مراجعة آلية |
| نظام التصميم | `references/design-system.md` + `templates/design-tokens.base.json` + `templates/presets/*.json` | رموز قابلة للتخصيص، 4 سمات جاهزة، فحص تباين رياضي |
| دليل المواد | `references/material-playbook.md` | كيف تجمع لقطات من كل نوع مادة (مع تمييز المُختبَر من غيره) |
| الأخطاء الشائعة | `references/pitfalls.md` | 22 حالة: المشكلة ← السبب ← الحل |
| دليل الطلاب | (ملف منفصل `02-student-guide.md`) | الخطوات العشر العامة للوصول لأفضل نتيجة |

**مناسبة لـ:** تعريف بمادة/موقع/مشروع، شرح مفهوم، مقاطع ترويجية 15–90 ثانية.
**غير مناسبة لـ:** فيديو بكاميرا حقيقية وتعليق صوتي مولَّد (لا تدعم الكلام حاليًا)، أو مواد تحتاج تسجيل دخول لا يمكن تشغيلها محليًا (**توقف واسأل**).

## 1) قواعد ثابتة (لا تتجاوزها)
1. **مجلد المادة للقراءة فقط.** لا تعدّل ولا تحذف أي ملف فيه. مخرجاتك في مجلد مشروع منفصل.
2. **لا رندر سحابي.** HyperFrames محلي على المعالج (`--no-browser-gpu`)، وعطّل بيانات الاستخدام: `hyperframes telemetry disable`.
3. **اطلب موافقة المستخدم قبل تثبيت أي برنامج** (npm/Chrome/Playwright…). الحزمة نفسها **لا تحتاج تثبيتًا** عدا HyperFrames للرندر.
4. **لا تخترع بيانات المادة** (أسماء، أرقام، روابط). إن لم يوجد رابط منشور فاسأل ولا تفترض.
5. **توقف عند نقاط المراجعة** وانتظر الموافقة: (أ) بعد فهم المادة واختيار اللحظات، (ب) بعد السيناريو، (ج) عند اختيار الموسيقى، (د) قبل الاعتماد.
6. **الخطوط من المادة نفسها** (أو مصدر رسمي مع تسجيل الرخصة) ومضمّنة base64؛ لا خطوط نظام.
7. **الموسيقى مرخّصة.** استخدم موصلًا مرخّصًا إن وُجد، وذكّر المستخدم بالتحقق من الرخصة قبل النشر.
8. **لا تنسخ** صورًا/صوتًا/نصوصًا من فيديو مرجعي؛ المرجع للأسلوب فقط.
9. **اكتب ملخصاتك بلغة المستخدم.**
10. **لا تعلن «انتهيت» قبل المراجعة الآلية والبصرية.**

## 2) ما تسأل عنه أولًا
| المعلومة | افتراضي |
|---|---|
| ما المادة وأين هي؟ وهل تُشغَّل محليًا؟ | — |
| الهدف: ماذا يفعل المشاهد بعد الفيديو؟ | — |
| الجمهور والمنصة | هاتف، عمودي، بلا صوت غالبًا |
| المدة | 30–60 ثانية |
| اللغة والاتجاه | حسب المادة (`ar`/`rtl` أو `en`/`ltr`) |
| الرابط: يظهر أم لا؟ | **لا تفترض** |
| الموسيقى: من يختار؟ | اقترح 3 وانتظر الاختيار |
| الإطار: لقطة مباشرة أم إطار جهاز؟ | **لقطة مباشرة بحواف متلاشية** (مجرّبة؛ الإطار يصغّر الأدوات الطويلة) |
| فيديو مرجعي للأسلوب؟ | اختياري |

## 3) خط العمل (عشر خطوات)
```
① الهدف ─► ② فهم المادة ─► ③ تجهيز المشروع ─► ④ جمع اللقطات ─► ⑤ السيناريو
     ─► ⑥ التصميم ─► ⑦ الصوت ─► ⑧ التوليد والرندر ─► ⑨ المراجعة ─► ⑩ التسليم
```

### ① الهدف
ورقة فكرة: هدف في جملة، جمهور، جملة يتذكرها، مدة، ما لا يظهر. (انظر دليل الطلاب، الخطوة 1.)

### ② فهم المادة **[توقف]**
اجرد العناصر وأعطِ كلًّا درجة (يتحرك؟ يُفهم بلا صوت؟ فرق واضح؟) واختر **3–5 لحظات**. للمواد الويب شغّل نسخة محلية واقرأ الكود لتحديد الأسماء الدقيقة للأدوات. اعرض النتيجة وانتظر الموافقة.

### ③ تجهيز المشروع
```bash
node <kit>/scripts/init.mjs <مجلد-المشروع> --preset dark-mint --lang ar
cd <مجلد-المشروع>
```
ثم: ضع **خطوط المادة** في `graphics/assets/fonts` وعرّفها في `fonts.json`، وعدّل `font.*` ولون التمييز في `design-tokens.json`، ثم:
```bash
node tools/check-tokens.mjs design-tokens.json     # يجب: ✅ مطابق
```
**HyperFrames:** ثبّته في **مسار بلا حروف عربية** (مثل `C:\hf-env`): `npm install hyperframes gsap`، ثم ضع مساره في `project.json → graphics.renderCommand[0]`. أول رندر ينزّل متصفحًا خاصًا (≈15 دقيقة مرة واحدة). **اطلب موافقة المستخدم أولًا.**

### ④ جمع اللقطات
حسب نوع المادة (`references/material-playbook.md`). لمواد الويب:
```bash
node tools/serve.mjs <مجلد-المادة> 5173          # قراءة فقط
# عدّل tools/scenarios.mjs (انظر scenarios.example.mjs) ثم:
node tools/record.mjs all --base http://localhost:5173    # → raw/<اسم>.mp4 + meta
```
تحقق **بصريًا** من 4 إطارات لكل مقطع: الأداة كاملة؟ المؤشر ظاهر؟ لا محتوى متسرب؟

### ⑤ السيناريو **[توقف]**
جدول: التوقيت · اللقطة · النص (≤7 كلمات) · الحركة · الانتقال. مشاهد 2–7 ثوانٍ. البنية المقترحة: افتتاح ← نظرة عامة ← قبل/بعد ← أمثلة تفاعلية ← دعوة. انتظر الموافقة.

### ⑥ التصميم
عدّل `scenes.json` (المشاهد والنصوص). **قِس العناوين** بـ`node tools/measure.mjs '[["العنوان",800,96,"h"]]'` (≤ 840px). المولّد يحذّر من تجاوز 7 كلمات.

### ⑦ الصوت **[توقف عند الاختيار]**
اقترح 3 مقطوعات هادئة بلا غناء (80–100 BPM مناسبة غالبًا)، ثم قصّ المختارة للمدة بنهاية طبيعية (أداة الموصل، أو `ffmpeg -t … -af afade=t=out`). ثم:
```bash
node tools/beats.mjs audio/music.mp3 --bpm <المعلن> --durations 5,4,6,...   # يقترح bounds على الضربات
```
ضع `bounds` الناتجة في `scenes.json` (آخر قيمة = المدة) و`duration` في `scenes.json` و`project.json`.

### ⑧ التوليد والرندر
```bash
node tools/prep-clips.mjs && node tools/gen-composition.mjs && node tools/make-fonts.mjs
<hyperframes> lint graphics        # 0 أخطاء (التحذيرات البنيوية مقبولة)
node build.mjs                     # رندر ← توحيد ← دمج ← موسيقى ← loudnorm ← ترميز ← صورة مصغّرة
```

### ⑨ المراجعة
```bash
node tools/review.mjs      # الأبعاد · المدة · الجهارة · الذروة · الهوامش الأربعة (يدعم السمات الفاتحة والداكنة)
```
+ ورقة مصغّرات (إطار من منتصف كل مشهد) ومراجعة بصرية + اختبارات بشرية (5 ثوانٍ، الصمت، الجوال).

### ⑩ التسليم **[توقف قبل الاعتماد]**
أرسل الفيديو والصورة المصغّرة، واذكر **بصراحة**: ما اختُبر وما لم يُختبر، التنبيهات (رخص، صغر نص بعض الأدوات)، وتحسينات مقترحة. اعتمد فقط بموافقة المستخدم.

## 4) بنية المشروع الناتج
```
<مشروع>/
├─ design-tokens.json   ← نظام التصميم (مصدر وحيد)
├─ scenes.json          ← المشاهد والنصوص والحدود (bounds)
├─ fonts.json           ← ملفات الخطوط
├─ project.json         ← الترميز والموسيقى والجهارة ومسار HyperFrames
├─ build.mjs            ← الرندر والمزج والتصدير
├─ tools/               ← record · prep-clips · gen-composition · make-fonts · measure · beats · review · check-tokens · serve · probe · make-thumbnail
├─ raw/  audio/  graphics/  work/  export/
```

## 5) أنواع المشاهد (scenes.json)
| النوع | الحقول |
|---|---|
| `title` | `title` (+`<em>` للكلمة المفتاحية) · `subtitle` · `tagline` |
| `media` | `media` (فيديو/صورة نسبةً للجذر) · `tag` · `swaps:[[ث,"نص"]]` · `wipe` · `kenburns` (للصور) · `from` (بداية الاقتطاع للفيديو) |
| `before` | `tag` · `title` · `lines:[3 أسطر]` |
| `cta` | `title` · `button` · `credit` |
لإضافة نوع جديد عدّل `tools/gen-composition.mjs` (كتلة `if (s.kind === …)`).

## 6) معايير القبول (كلها ✅)
- المدة المطلوبة (±0.1s) · 1080×1920 · 30fps · AAC 48kHz.
- ‎−14 LUFS (±0.5) · ذروة حقيقية ≤ ‎−1.5 dBTP.
- `review.mjs` نظيف (لا عنصر في الهوامش).
- `check-tokens.mjs` ✅ · عناوين ≥ 80px · ثانوي ≥ 48px · ≤ 7 كلمات · لا خط بديل.
- كل أداة ظاهرة كاملة وبمؤشر يوضّح التفاعل · لا محتوى متسرب.
- الرخص (خطوط، موسيقى، صور) مسجّلة.

## 7) حدود المهارة (بصراحة)
**اختُبر فعليًا:** مواد ويب (موقع تعليمي حقيقي + صفحة تجريبية) بمؤشر ماوس · مشاهد عنوان/قبل/وسائط/دعوة · سمة داكنة (Dark Mint) وسمة فاتحة (Light Paper) برندر كامل وصوت ومراجعة آلية · عربية RTL · رندر HyperFrames على المعالج · معايرة ‎−14 LUFS · تحليل ضربات · المراجعة الآلية.
**اختُبر جزئيًا:** الإنجليزية LTR مع Midnight Blue: توليد المشاهد ولقطات فقط (بلا رندر كامل ولا صوت) · سمة Warm Dusk: فحص رياضي للتباين فقط.
**لم يُختبر:** PDF/شرائح/تطبيقات جوال/كود/بيانات (توصيات فقط) · أنظمة غير ويندوز · مواد بتسجيل دخول.
**قيود تقنية:** مسارات Edge/Chrome مضبوطة على ويندوز · تقدير BPM تقريبي (مرّر `--bpm` المعلن) · لا يدعم الكلام/التعليق · أنواع المشاهد الأربعة (قابلة للتوسعة) · الأدوات الطويلة جدًا تُصغَّر لتظهر كاملة.
**رخص:** تحقق من رخصة الخطوط والموسيقى والصور المستخدمة.
